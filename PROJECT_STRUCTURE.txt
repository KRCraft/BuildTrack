Integration notes:
- Frontend -> Backend: NEXT_PUBLIC_API_URL (http://localhost:8000/api/v1) + Authorization: Bearer <access> + X-Company-ID header + credentials:include (HttpOnly refresh at /api/v1/auth/refresh/)
- CORS: backend allows http://localhost:3000, http://localhost:5173, http://127.0.0.1:3000 (dev), Vercel URL (prod via env)
- Auth: /api/v1/auth/register|login|refresh|logout|me -> SimpleJWT (15m access, 7d refresh rotation+blacklist)
- Compose health: db pg_isready + backend healthcheck + frontend depends_on backend healthy; redis optional.
